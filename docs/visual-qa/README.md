# 本丸3D 外観調整の確認

2026-09-06。画像はユーザーの保存済み本丸ではなく、独立したブラウザコンテキストに作った検証用配置（部屋1室・景観／建築14個）です。

## 変更

- 屋根と門：墨青の瓦、4分割した反り、瓦筋、破風・軒先・棟の厚み。
- 部屋：既存の開放面を残して柱、腰板、奥壁の小さな瓦庇を追加。
- 庭：角を丸めた芝、低い濃淡。植栽の根元に盛り土・庭石と接地影。
- 池・橋：大小の岸石、淡い波紋、橋の桁の陰色。
- 松・竹：松の冬の雪、竹の葉の密度を増加。
- 全体：地面の斑点模様を抑え、時間帯ごとの照明の強さを調整。
- 描画：同じ形状・材質の部材をパーツ単位でインスタンス化。保存形式や部屋・家具・男士の配置処理は変更なし。

## 確認結果

- Headless Microsoft Edge / Playwright、1200×850 と 390×844。
- 春夏秋冬 × 朝昼夕夜、全16組み合わせで JavaScript 例外なし。
- 切り替え前後で buildingObjects と roomLayouts の内容が同一。
- インスタンス化した橋に対する raycaster のヒットを確認。
- 春と冬のスクリーンショットを目視確認。スマホ幅でも描画できることを確認（ズーム位置によって全体は画面外にはみ出す）。
- 検証配置で冬のデスクトップ140 draw calls / 18,406 triangles、春のスマホ幅145 draw calls / 15,874 triangles。季節が違うため直接の負荷比較ではありません。
- 実機スマホのFPS・ユーザー固有の大規模配置・全編集操作については未測定。
